# 🚀 Free WordPress Plugins

A collection of FREE and lightweight WordPress plugins designed to improve your website with modern features, better performance, and an enhanced user experience.

---

## 🌙 1. 508 Dark / Light Mode

**508 Dark Mode** is a lightweight WordPress plugin that adds a smooth, user-controlled dark mode to any website using the powerful **DarkReader** engine.

Unlike heavy theme-based solutions, it works independently of your theme and dynamically generates a beautiful dark mode without modifying your existing CSS.

### ✨ Features

- 🌙 Adds Dark Mode to any WordPress website
- ⚡ Powered by the DarkReader engine
- 💾 Saves user preference using `localStorage`
- 🎨 Compatible with all WordPress themes and page builders
- 🔗 Includes a ready-to-use shortcode: `[508_dark_mode]`
- 📱 Optional automatic insertion into the mobile menu
- 🎛️ Modern animated toggle switch
- 🚀 Prevents Flash of Unstyled Content (FOUC) by loading DarkReader early

## 📧 2. Email Marketing Scheduler

A simple and efficient email scheduling plugin for WordPress.

### ✨ Features

- ⏰ Schedule emails for a specific date and time
- 📤 Control the number of emails sent per batch
- 🖥️ Uses your server's native mail functions
- 📋 Import and manage mailing lists
- 📈 Reduce server load by sending emails gradually
- 🎯 Perfect for newsletters and email campaigns

## 📊 3. UTM Analysis

Track and analyze your marketing campaigns directly inside WordPress.

### ✨ Features

- 🔍 Automatically captures UTM parameters from incoming URLs
- 💾 Stores campaign data in the WordPress database
- 📈 Displays useful statistics and reports
- 🎯 Helps evaluate advertising and marketing performance
- ⚡ Lightweight with no external tracking services required

## 🤖 4. WordPress AI Chat Assistant (FREE)

A powerful, privacy-friendly AI chatbot for WordPress that supports multiple AI providers and allows you to build an intelligent customer support assistant **without paying for ChatGPT**.

Simply connect your own API key (Groq, Google Gemini, OpenAI-compatible APIs, and more) and start chatting.

🌐 [Live Demo](https://anamadar.com)

### ✨ Features

- 🤖 Supports multiple AI providers
  - Groq
  - Google Gemini
  - OpenAI-compatible APIs
  - Cerebras AI
  - And custom provider ...
- 🔑 Use your own API key
- 📚 Knowledge Base support
  - Add your own content
  - The AI answers customers **only using your provided information**
- 🌙 Dark & Light Mode
- 🌍 Multi-language support
- ✨ Auto Failover
  - If the current provider fails, automatically try other models or providers that have API keys configured.
- 💬 Custom AI personality and tone
  - Friendly
  - Professional
  - Sales-focused
  - Technical
  - Or define your own style
- ⚙️ Easy configuration panel
- 📱 Responsive design
- 🚀 Fast and lightweight
- 🔒 Privacy-friendly (your own API key, your own data)
- 🎨 Modern chat interface
- 🛠️ Many more customization options
